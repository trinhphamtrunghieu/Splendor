# Image credits

No third-party images are installed in this repository right now. The gems, card
faces and noble tiles you see are drawn as vector artwork in
`assets/js/art.js`, which is covered by this project's MIT licence.

To install real photographs and paintings, run:

```bash
node tools/fetch-art.js
```

That script downloads only public-domain and free-licensed files, and rewrites
this file with a row per image recording its source, author and licence. See
`assets/img/README.md` for installing your own images by hand instead.

## Not included

Splendor is designed by Marc André and published by Space Cowboys. The retail
